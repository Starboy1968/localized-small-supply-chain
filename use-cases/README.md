# Use Cases: Worked Examples

Three end-to-end scenarios that show the existing prompts in action, with sample data you can paste or upload into any AI chat tool.

> **Fictional.** Every business, vendor and number is made up. Each "sample AI output" is an **illustrative example** of a good answer, not output from a real tool run.

| # | Scenario | Sample data | Prompts used |
|---|---|---|---|
| 1 | [A small cafe's weekly stock: waste and par levels](cafe-weekly-stock.md) | [Stock sheet](../sample-data/juniper-cafe-stock-sheet.csv) | 12, 7, 5 |
| 2 | [A local retailer's forecast, overstock and dead stock](retail-forecast-overstock-dead-stock.md) | [Sales history](../sample-data/fern-twine-sales-history.csv) | 9, 10, 11 |
| 3 | [A buyer comparing local vendors' lead times and reliability](vendor-lead-times-reliability.md) | [Delivery log](../sample-data/little-pine-deli-delivery-log.csv) | 14, 15 |

## Every scenario has the same parts
- [ ] **The situation:** who, what's going wrong, what they want to know
- [ ] **Sample input:** a CSV in [sample-data/](../sample-data/), also shown inline
- [ ] **Which prompts to use,** in order, with the placeholders filled in
- [ ] **How to give the AI the data:** paste the CSV text, or upload the file if your tool allows it
- [ ] **Sample AI output,** labeled as illustrative
- [ ] **Human check:** what to verify and what to do next

## Try it yourself
1. Download one of the sample CSVs, or copy it from the page.
2. Copy the matching prompt from the use case page.
3. Paste the data (or upload the file) into any AI chat tool.
4. Compare its answer with the illustrative one. Note anything that's different or wrong.
5. Swap in your own data once you're comfortable.
